# Keyboard only portfolio walkthrough

Target length: 90 seconds. Use the published site after deployment. Start the recording with the page loaded and the browser page focused. Do not click or use the trackpad during the demonstration. Narrate the actions below, or use a recorder that displays key presses. Do not submit a contact message.

| Time | Keys and action | Suggested narration |
| --- | --- | --- |
| 0–10 sec | Start at the top; press Tab. | “I am navigating my portfolio using only the keyboard. The first Tab reveals the skip link and a visible focus indicator.” |
| 10–20 sec | Press Enter, then Tab. | “The skip link bypasses navigation and moves to the main content. My next Tab reaches the projects link.” |
| 20–35 sec | Press Enter on See my projects; use Down or Page Down to browse. | “Activating the link takes me to Projects and focuses the section. I can read through the project cards without using a mouse.” |
| 35–50 sec | Continue Tab to the next content link, then to contact links. Use Shift+Tab once. | “Tab follows the document order. Shift Tab lets me move backward. The focus outline makes my position clear.” |
| 50–65 sec | Tab through contact links into Name; type Demo Visitor. Tab to Email; type demo@example.com. | “Every form control has a visible label. Required fields are identified, and the browser supplies native controls.” |
| 65–80 sec | Tab to Topic; use arrow keys to choose a topic. Tab to Message and type Keyboard navigation test. | “I can choose a topic with the keyboard and enter a message. There are no mouse-only controls or focus traps.” |
| 80–90 sec | Tab to Send message, then Tab to Back to top and press Enter. Do not submit. | “I can reach the submit button without sending a test message. Back to top returns me to the beginning. The published page scores 100 for accessibility in PageSpeed Insights.” |

If the browser initially focuses its address bar, press Tab until the page's skip link is focused. For native select menus, opening and closing keys vary by browser; arrow keys select options once the control is focused.

Stop at 1–2 minutes. Save as MP4 or MOV and review that the focus indicator and narration or key captions are readable. Submit the video together with the published site, repository, and score screenshot.
